# 기말고사 주말 제출 변경 기록

## 구성과 운영 영향

- 기존 일일 기간과 91개 기록일은 그대로 보존한다. 별도 주말 기간에 8개 기록일만 만든다.
- `terms.submission_mode`는 기존 행에 `daily` 기본값을 부여한다.
- `classes.public_term_id`는 학생 화면과 제출 서버가 사용할 운영 기간을 지정한다.
- `term_participants`는 기간별 참여 학생을 관리한다. 공개 역할에는 조회/수정 권한이 없고 담당 교사만 확인한다.
- 기간 생성, 참여자 변경, 공개 기간 지정 RPC는 담당 교사를 검사한다. 제출과 결과 복구 RPC는 서버 역할만 호출한다.
- 기존 제출, 사진, 이력과 학생 활성 상태를 변경하는 데이터 마이그레이션은 없다.
- 공개 기간이 바뀐 뒤 오래된 화면에서 제출하면 `term_changed`로 거절한다. 접수 복구는 원래 기간/학생/날짜/요청 번호가 일치해야 한다.
- 토요일과 일요일은 각기 기존 날짜별 제출 API와 별도 이미지 세트를 사용한다. 서버 오류로 확정 여부가 불명확하면 업로드 사진을 삭제하지 않는다.
- 최종 접수 종료는 2026-12-07 23:59:59.999 KST로 정했다. 각 월요일 마감 이후 지각 제출을 허용하되 시험 시작 후에는 신규 접수를 받지 않는다.
- 신청 학생 명단은 임의로 채우지 않는다. 실제 신청자 선택은 교사가 명단 화면에서 한다.

## 화면

- 학생: 한 열로 배치한 두 날짜의 사진 선택, 미리보기, 개별 삭제, 선택 사용 시간, 하나의 제출 버튼, 확인창, 날짜별 결과.
- 교사: 주말 기간 설정, 참여자 체크와 저장, 주말별 0/2~2/2 현황, 날짜별 검토, 같은 학생의 두 날짜 사진 비교.
- 기존 일일 모드, 학생 상세 이력, 교사 검토와 재제출 허용은 유지한다.

## 검증

- 기존 상태 계산 46개, 파일 검증 14개, 초기 DB 권한 71개, 공개 제출 DB 35개, 사진 세트 DB 41개.
- 주말 DB 24개: 월요일 개시, 09:00 경계, 참여자와 RLS, 마감 소급 변경 금지, 기간 충돌, 요청 재생, 응답 복구, 기존 행 보존.
- 별도 스크립트: 데모, 부분 재시도, 재진입 복구, 토큰 분리, 확정 응답 유실 시 사진 보존, 실제 Edge 핸들러의 로컬 실행.
- 브라우저: 390px 모바일에서 미리보기, 삭제, 두 날짜 확인창, 일부 접수 표시와 복구를 확인한다.
- 운영 프로젝트에는 합성 제출을 만들지 않는다. 변경 전후 기존 데이터의 개수와 행 지문을 비교한다.

## 배포 구분

1. 새 Supabase migration을 적용한다. 기존 행의 날짜/시간을 바꾸지 않는다.
2. `submit` Edge Function을 배포한다. 공개 학번 제출 구조에 맞춰 기존 `verify_jwt=false`를 유지하며 서버 검증을 사용한다.
3. GitHub `main`에 검증한 소스를 저장하고 GitHub Pages `gh-pages`에 production 빌드를 게시한다.
4. 새 주말 기간을 생성하고 공개 기간으로 지정한다. 참여자는 기본 0명이며 교사가 신청자를 선택한다.

이전 이미지 정리, 자료 삭제, DB 초기화는 실행하지 않는다.

- 운영 서버의 6개 날짜는 요청한 세 주말에 한정되며, 각각 월요일 00:00 개시와 09:00 마감을 공유한다. 실제 웹 화면에서도 첫 제출이 11월 21~22일 기록, 11월 23일 접수로 표시됨을 확인했다.

- 최종 공개 기간 지정 후에도 기존 제출 123건, 이미지 행 151건, 제출 이벤트 130건, Storage 객체 158개, 기존 기록일 91개의 개수와 행 지문이 변경 전과 일치했다. 기존 학생 명단과 운영 기간의 지문도 일치했다.
- 운영 데이터에 합성 제출을 추가하지 않았다. 사진 제출과 교사 비교는 로컬 데모, 서버 계약은 격리된 DB와 Edge 검증으로 확인했다. 모바일 검증은 390px 브라우저 기준이며 실제 휴대전화의 기본 사진 선택기는 별도로 시험하지 않았다.
- 빌드는 성공했다. Vite의 JavaScript 번들 크기 경고(500kB 초과)는 남아 있다.
- 로컬 `.git` 쓰기 권한 제한으로 커밋과 배포는 GitHub 연결에서 완료했다. 로컬 소스 파일은 수정되었지만 로컬 Git HEAD와 인덱스는 이전 상태다.
